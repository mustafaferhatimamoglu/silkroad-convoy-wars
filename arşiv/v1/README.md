# V1 arşivi (kurtarılan kod)

V1 bir git deposu değildi; buradaki dosyalar 2026-10-31'de Geri Dönüşüm Kutusu'ndan kurtarıldı.

- `tools/map_export/`: orijinal istemcinin PK2 dosyalarından harita, model, minimap, müzik, partikül ve zindan dışa aktarıcıları. Yollar eski klasör düzenine (Silkroad_V2/V3) göre sabit yazılmış; kullanmadan önce güncellenmeli.
- `tools/*.py`: harita/şehir inceleme betikleri.
- `silkroad_3d/`: V1 oyun kodu.
- `MAP_CALISMA_OZETI.md`: harita çalışması notları.
- `v3_test_kartal.py`: V3'te commit edilmemiş kalan test.

Orijinal istemci (telifli, depoya konmaz) resmi Silkroad Online Global kurulumundan yeniden indirilebilir.
